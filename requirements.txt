# batchaug is NOT on PyPI — install from the MRI2CT clone:
#   pip install --no-deps -e /home/minsukc/MRI2CT/batchaug/
#
# --no-deps still recommended so pip doesn't re-resolve the pinned torch stack.
# batchaug ships a triton backend wanting `triton>=3.0`; torch 2.13 now provides
# the matched triton 3.7.1, so that requirement is satisfied. We nonetheless
# force the PyTorch backend at runtime for reproducibility:
#
#     import batchaug as B
#     B.set_backend("pytorch")   # NOT "triton" or "auto"
#
# The PyTorch backend works on any torch>=2.0. Augmentation runtime is dominated
# by model forward/backward, so the triton backend's speedup is noise; switching
# to it is an optional, separately-verified optimization.
#
# torchaudio (unused) and triton are transitive: `pip install torch==2.13.0`
# from PyPI pulls the cu130 build + triton 3.7.1 automatically. fused_ssim (the
# optional refiner-SSIM loss / SSIM-3D metric) is a CUDA extension rebuilt from
# git against the active torch — see docs on the torch-2.13 upgrade.
